## SEO Strategy Notes

### Where Keywords Were Applied (5 Methods)

1. **Meta Keywords Tag** — Every page received 10–15 additional keywords in `<meta name="keywords">`. While Google largely ignores this tag, Bing and other search engines still index it.

2. **Content Text (Headings & Paragraphs)** — Keywords were naturally woven into H2/H3 headings, paragraph text, card titles, and card descriptions. This is the most impactful SEO signal — Google ranks pages based on visible, readable content.

3. **Image Alt Attributes** — Descriptive, keyword-rich alt text was added to key images on `index.html` and `team.html`. This improves image search visibility and accessibility.

4. **JSON-LD Structured Data** — The `description` field in JSON-LD `@type: Event` and `@type: Organization` schema was enriched on `index.html`, `blog.html`, `genesis.html`, and `techastra.html`.

5. **Meta Descriptions** — Enhanced on `blog-post.html` and implicitly via JSON-LD on other pages.

### Best Practices Followed

- **Natural language** — Keywords are embedded in readable sentences, not keyword-stuffed
- **Semantic variations** — Different forms of the same concept (e.g., "startup", "startups", "student startup", "college startup India")
- **Long-tail keywords** — Included phrases like "how to start a startup in college India", "free startup workshop near me"
- **Geographic targeting** — Consistently added "Navi Mumbai", "CSMU", "Panvel", "Maharashtra" for local SEO
- **Brand consistency** — "IIEC", "E-Cell CSMU", "Chhatrapati Shivaji Maharaj University" appear across all pages
- **Event-specific keywords** — Each event page (GENESIS, TechAstra) has unique, relevant keywords
